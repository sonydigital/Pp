# PromptPlay — план реализации

## Подход
PromptPlay — одностраничная Next.js App Router студия для обучения детей 7–15 лет AI-промптингу и vibe-coding. Интерфейс работает без аккаунта: клиент хранит текущую лигу, чат и сгенерированный код в состоянии React, а серверный `/api/generate` либо вызывает официальный OpenAI SDK через `OPENAI_BASE_URL`/`OPENAI_API_KEY`, либо возвращает встроенную безопасную Canvas-игру в демо-режиме.

На клиенте рабочая область разделена на урок/чат и live game screen. Код игры передаётся в sandboxed `iframe` через `srcDoc`; ответ API обновляет чат и iframe. История для API ограничивается последними двумя сообщениями, а текущий HTML отправляется отдельно.

## Структура проекта
- `app/page.tsx` — parent-friendly landing portal с возрастными лигами, программой, безопасностью, тарифами и footer.
- `app/academy/page.tsx` — Course Map, теория/тренажёр, экран студии, лига, миссия, чат, prompt-блоки, iframe и модальные окна.
- `app/legal/LegalPage.tsx` и `app/legal/*/page.tsx` — русские страницы оферты, конфиденциальности и контактов.
- `src/data/lessons.ts` — типы и агрегатор 30 уроков, по 15 для каждой возрастной лиги.
- `src/data/leagueJunior.ts` — 3 модуля × 5 уроков для Исследователей (7–10 лет) с русской теорией и тренажёрами.
- `src/data/leagueSenior.ts` — 3 модуля × 5 уроков для Создателей (11–15 лет) с русской теорией и тренажёрами.
- `src/lib/supabase.ts` — optional Supabase browser client, активный только при наличии публичных env keys.
- `supabase/schema.sql` — profiles table, signup trigger и RLS policies для собственного профиля пользователя.
- `app/globals.css` — Tailwind directives и кастомная визуальная система PromptPlay.
- `app/layout.tsx` — metadata, русская локаль, корневой shell.
- `app/api/generate/route.ts` — серверная генерация, строгий system prompt с `mission_completed`, демо-fallback и валидация JSON.
- `lib/demo-game.ts` — самодостаточная Canvas-игра космического кота, starter-варианты и стартовые сообщения.
- `public/manus-routes.json` — декларация `/`, `/academy` и трёх legal-маршрутов.
- `app.config.ts` — metadata для логотипа проекта.

## Дизайн

### Три направления
- Neon Playground — 0.06: сочные игровые карточки, неон и крупные пиксельные акценты.
- Paper Quest — 0.04: тёплая бумажная фактура и наклейки-подсказки.
- **Cosmic Sticker Lab — 0.08 (выбрано)**: мягкая светлая база, конфетные карточки и маленькая космическая лаборатория вокруг игры.

### Design Movement
Cosmic Sticker Lab — playful edtech UI, который соединяет дружелюбную лабораторию, наклейки и интерфейс игрового редактора.

### Core Principles
1. Каждый блок должен выглядеть как понятный игровой предмет: миссия, чат, сцена или бонус.
2. Контрастная иерархия: крупные заголовки и кнопки для быстрых действий, спокойные подсказки для обучения.
3. Возрастная адаптация должна менять плотность и способ ввода, а не только цвет активной вкладки.
4. Все интерактивные элементы дают понятную обратную связь: hover, active, focus и небольшая физика нажатия.

### Color Philosophy
Основа — молочный «космический холст», на нём фиолетовый как цвет AI-магии, жёлтый как награда XP, мятный как сигнал готовности и коралловый как акцент действия. Цвета должны быть жизнерадостными, но текст остаётся тёмно-синим для читаемости.

### Layout Paradigm
На desktop — асимметричная лаборатория: узкая вертикальная левая лента обучения и большая правая сцена с рамкой игрового автомата. На мобильном — последовательная история миссии: шапка, миссия и наставник, затем живая сцена.

### Signature Elements
- Логотип-ракета в пузыре и слово PromptPlay.
- Пунктирные звёздные дорожки вокруг карточек.
- Толстые скруглённые рамки и тени как у наклеек.

### Interaction Philosophy
Ребёнок всегда видит следующий маленький шаг: нажать блок, дописать промпт, запустить игру или поделиться. Кнопки имеют короткие русские подписи и иконки Lucide; опасных или взрослых тем в интерфейсе нет.

### Animation
Использовать лёгкое плавание звёздных декораций, мягкий `float-in` для сообщений и короткое пружинное уменьшение при нажатии. Не использовать постоянные мигания; уважать `prefers-reduced-motion`.

### Typography System
Использовать системный стек `Nunito, ui-rounded, system-ui` с жирными display-заголовками и обычным текстом 14–16px. Числа XP и бейджи — крупные и плотные.

### Brand Essence
PromptPlay — маленькая AI-студия, где ребёнок превращает идею в игру за несколько добрых шагов. Характер: любопытный, поддерживающий, игровой.

### Brand Voice
Заголовки: «Твоя идея — уже начало игры»; CTA: «Запустить магию». Микрокопия: «Добавь один штрих — и проверь сцену».

### Wordmark & Logo
Ракета внутри круглой наклейки, у которой иллюминатор сделан как точка буквы i в PromptPlay.

### Signature Brand Color
`#6D5DFB` — Prompt Purple, собственный цвет действия и AI-идеи.

## Сервер и frontend
Next.js запускается на порту 3000. Серверный route использует `openai` только на сервере и никогда не раскрывает ключ браузеру. Демо-режим запускается при отсутствии ключа или при невалидном ответе модели. Tailwind используется для структуры, а CSS-переменные и utility-классы — для фирменной палитры. Родительский портал живёт на `/`, а академия доступна по `/academy` одним кликом.

## Учебная модель
Пользователь проходит локальный трёхшаговый flow: 1) три карточки «Теория на пальцах» с аналогиями и сравнением плохого/хорошего промпта, 2) тренажёр с мгновенной проверкой, 3) практическая миссия в starter Canvas-студии. Теория и тренажёр не вызывают API. Course Map группирует 30 уроков по трём модулям в каждой лиге, сохраняет XP и выполненные уроки в `localStorage`; уроки 1–3 свободны, 4–15 закрыты за PRO-демо paywall. Счётчик генераций хранится по дате и ограничен 15 запросами в сутки.

## Auth и persistence
Guest mode работает без env-ключей и продолжает хранить прогресс в `localStorage`. При настройке `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` кнопка «Войти / сохранить» открывает email/password auth; после входа локальные XP и completed lessons объединяются с `profiles`, а новые progress, PRO и daily generation updates синхронизируются в cloud. PRO modal закрыт для гостя до авторизации, чтобы подписка была связана с аккаунтом.
