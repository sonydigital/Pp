- [x] **POST /api/generate и демо-режим**
  - Маршрут использует официальный `openai` SDK с `process.env.OPENAI_BASE_URL` и `process.env.OPENAI_API_KEY`.
  - В route передаются только точный system prompt, текущий HTML-код и последние 2 user/assistant сообщения.
  - Ответ — строгий JSON по схеме `{ "mentor_message": "string", "code": "string", "mission_completed": boolean }` без markdown.
  - При отсутствии `OPENAI_API_KEY` возвращается рабочая встроенная Canvas-игра и русское сообщение наставника.
  - Модельные ошибки и невалидный JSON безопасно откатываются к демо-ответу.
